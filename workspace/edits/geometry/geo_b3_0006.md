# 축하합니다! — 사용자 제공 이미지 모델

geometry 0x30006. 제작원: `workspace/artwork/geometry-28/geo_b3_0006-source.png`.

현재 모델은 20,720바이트 / 889삼각형이다. 제공 이미지의 아치 배치·느낌표·갈색을 사용했으며 폰트 파일은 사용하지 않았다.

원본 루트+10개 노드, 애니메이션 0x3000C/0x3000D/0x3000E, 재질·렌더 상태 복구 명령을 보존했다. ROM의 FF 패딩에 배치하고 테이블 0x709E4를 갱신했다.

적용 ROM: `build/kirby64-ko-graphics-20261112-v3.z64`. 형편없네요 모델과 PNG 350개도 포함한다. 저장 후 재추출·체크섬·변경 범위 검사는 통과했으며 실제 게임 애니메이션은 미검증이다.
